# 手動受け入れテスト

実行前に `npm ci` と `npm run build` を完了し、`extension/` を Chrome の「パッケージ化されていない拡張機能を読み込む」から読み込む。表示された Extension ID を記録する。

次に使用 OS 用インストーラーを実行する。`<EXTENSION_ID>` は読み込んだ拡張機能の ID に置き換える。

```sh
# macOS
bash install/macos.sh <EXTENSION_ID>

# Linux
bash install/linux.sh <EXTENSION_ID>
```

```powershell
# Windows PowerShell
.\install\windows.ps1 -ExtensionId <EXTENSION_ID>
```

Chrome を完全に再起動してから、拡張機能の設定で有効な URL 正規表現、コピー元、空のコピー先を設定する。コピー元には `one.pdf` と `two.pdf` を作成する。

| ケース | 操作 | 期待結果 | 実施結果 |
| --- | --- | --- | --- |
| 単一タブ | `one.pdf` を抽出する URL を選択して実行 | 1 件コピー。閉じる設定がオンなら対象タブを閉じる | 未実施 |
| 複数タブ | `one.pdf` と `two.pdf` を抽出する URL を複数選択して実行 | 2 件コピー。対象タブをすべて閉じる | 未実施 |
| 重複タブ | `one.pdf` の URL を 2 タブ選択して実行 | ファイルは 1 件だけコピー。2 タブとも閉じる | 未実施 |
| URL 異常 | URL 不在、不一致、キャプチャなし、空キャプチャを含める | Native Host を呼ばず、コピーもタブクローズもしない | 未実施 |
| 事前検証異常 | source 不在、コピー先衝突、コピー元・先のディレクトリ不在を作る | 問題を表示し、ファイルを一切コピーせず、タブを閉じない | 未実施 |
| 途中失敗 | 事前検証後にコピー先へ同名ファイルを作成して競合させる | 先行分だけ残り、後続をコピーせず、タブを閉じない | 未実施 |
| 閉じる設定オフ | 「コピー成功後にタブを閉じる」をオフにして成功させる | コピー成功後も対象タブを閉じない | 未実施 |

OS ごとに Host 登録までを確認し、少なくとも一つの OS で表の全ケースを完了したら、最終列を実測結果へ更新する。アンインストールは各 `install/uninstall-*` スクリプトで行う。
